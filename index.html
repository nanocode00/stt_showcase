쇼케이스 환경 및 판정 기준 안내

1. 완전 독립 정적 배포: 본 쇼케이스는 외부 API, 마이크 권한 요청, 백엔드 서버 없이 GitHub Pages에서 100% 정적으로 동작하도록 제작되었습니다. 모든 음성은 상대 경로의 WAV 파일로 제공됩니다.

2. 판정 기준 (Comparison): 수사 표기 차이(예: '두 잔' vs '3잔')나 띄어쓰기 차이는 실제 키오스크 시스템의 NLU 및 Order Engine에서 동일한 정규화 엔티티로 매핑되므로 주문 의도 일치로 판정합니다.

3. 재현 메타데이터: 전체 5개 음성의 정밀한 샘플레이트, CPU 인퍼런스 지연시간(ms), 전사 데이터는 data/results.json ↗ 파일에 기록되어 있습니다.
